## 六、问题与修复记录

1. **Gradle 首次不能启动**：沙箱不允许在 `~/.gradle/native` 创建 `libnative-platform.dylib.lock`。错误为 `Operation not permitted`。经授权使用现有本机 Gradle 缓存后构建成功；没有更改系统、Git 或代理配置。
2. **错误弹框后的第一次自动续跑仍失败**：自动点击落在 AlertDialog 按钮边界外，后续输入被弹框拦截。logcat 如实显示第二次仍鉴权失败。随后重启到干净状态，正确路径成功；无效的 03 截图已被真实 50% 进度截图覆盖。
3. **返回键专项测试首次启动竞态**：`pm clear` 正在异步删除旧任务时 monkey 启动新进程，系统随后以 `remove task` 杀死该新进程并停留在 splash；不是应用异常。显式 `am force-stop` 后使用 `am start -W` 等 Activity 完整显示，再跑专项测试，结果通过。
4. **Lint 首跑 1 个错误**：API 33+ 分支已经使用 `RECEIVER_NOT_EXPORTED`，但 Lint 同时检查到 API 32 及以下必须调用的旧 `registerReceiver(receiver, filter)` 重载，报告 `UnspecifiedRegisterReceiverFlag`。由于旧 API 没有 flag 重载，在兼容方法上添加精确 `@SuppressLint("UnspecifiedRegisterReceiverFlag")` 及原因注释，未创建 baseline；随后重跑 Lint 通过。
